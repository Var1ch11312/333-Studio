# Вкладка «Экскурсии» — ожидаемые колонки

Ваша таблица уже существует. Бот читает все колонки строки и отдаёт их агенту как есть,
поэтому **точные названия не критичны** — но для красивых карточек желательно иметь:

| Колонка | Пример | Используется для |
|---|---|---|
| Название | Джип Сафари | поиск по тексту менеджера |
| Время | 08:00–18:00 | карточка / время сбора |
| Цена взрослый | 60 BGN | расчёт суммы |
| Цена детский | 30 BGN | расчёт суммы |
| Дни | Вт, Чт, Сб | дни отправления |
| Компания | XYZ Tours | карточка |
| Описание | Поездка в горы... | краткое описание |

Если у вас цена записана одной колонкой «Цена (взрослый/детский)» — это тоже работает,
агент разберёт текст. Но для точного автосчёта суммы лучше две отдельные числовые колонки.

> После импорта workflow откройте ноду **Excursions** и выберите реальную вкладку
> из выпадающего списка (n8n подтянет настоящие названия колонок).
