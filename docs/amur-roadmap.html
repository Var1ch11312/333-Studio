B

Как работает заказ — полный флоу

От клика по букету до фото-подтверждения доставки. Всё автоматизировано через WhatsApp + Supabase Realtime.

1
Клиент выбирает букет → Корзина
Каталог с фильтрами, карточка продукта, qty stepper. Multi-product корзина с localStorage. Проверка нечётного числа стеблей (болгарская традиция).
2
Checkout — имя, адрес, время доставки
5-шаговая форма. Адрес → определение зоны (Haversine) → автоматический расчёт цены доставки: Центр/Север 5 EUR, Меден Рудник 8 EUR.
3
Stripe Checkout — оплата картой
Деньги списываются сразу (не hold). PCI на стороне Stripe. После payment_intent.succeeded — webhook создаёт заказ в Supabase и запускает routeOrderToHub().
4
WhatsApp флористу ближайшего Hub
Алгоритм находит ближайший Hub по Haversine. WhatsApp кнопки «Принять» / «Отклонить». Таймаут 5 мин — автоэскалация к следующему Hub.
Все Hub отказали
Admin получает WhatsApp-алерт. Заказ переходит в ручную обработку со статусом escalated.
Hub принял
Запускается dispatchToCouriers() — broadcast всем доступным курьерам зоны.
5
Dispatch курьеров — first-wins
WhatsApp broadcast курьерам зоны. Первый нажавший «Принять» атомарно закрепляет заказ за собой (Supabase atomic update). Остальные получают «уже занято».
6
Доставка + фото-подтверждение
Курьер обновляет статусы: собираем букет → везём → доставлено. При доставке загружает фото через Hub Dashboard. Клиент получает signed URL фото в WhatsApp. SLA: весь цикл ≤ 2 часов.
Болгарское правило: букеты содержат нечётное число стеблей. Чётное — только для погребений. isOddFlowerCount(n) проверяется на уровне API при создании заказа. Менять нельзя — это жёсткое бизнес-правило.
