## CR-1 — Авто-звонок в компанию для проверки мест (Vapi) 🔜

**Статус:** запланировано (не реализовано)
**Решения приняты:** сервис — **Vapi**; язык звонка — **болгарский**.

### Что делает
После ввода данных клиента бот, параллельно с выдачей чека, запускает AI-голосовой
звонок в туркомпанию и узнаёт наличие мест. Менеджер продолжает общаться с клиентом,
а через ~30–60 сек получает в тот же Telegram-бот уведомление:
- ✅ Места есть
- ❌ Мест нет
- ⚠️ Мало мест (меньше, чем нужно)
- 📵 Не взяли трубку

### Что нужно подготовить
1. **Аккаунт Vapi** (vapi.ai) + API-ключ + подключённый исходящий номер (Vapi/Twilio).
   Стоимость ориентировочно ~$0.05–0.15/мин.
2. **Колонка «Телефон»** во вкладке «Экскурсии» (рядом с «Компания») — номер в формате +359…
3. Текст-скрипт звонка на болгарском (черновик ниже).

### Архитектура (добавляется к текущему workflow)
```
[Существующий AI Agent]
   └─ новый Tool: start_availability_call(excursion, date, seats, phone)
         → HTTP Request → POST https://api.vapi.ai/call
              (assistant со structured output: status = есть|нет|мало|нет_ответа)
         → боту сразу: «📞 Звоню в компанию, узнаю места…»

[Новый Webhook-workflow «Vapi result»]
   Webhook (POST /vapi-result)   ← Vapi присылает итог звонка
      → Code: распарсить status, seats
      → Telegram send менеджеру: ✅/❌/⚠️/📵 + детали
```

### Структурированный результат (Vapi assistant → JSON)
```json
{
  "available": "yes | no | few | no_answer",
  "free_seats": 0,
  "comment": "строка"
}
```

### Черновик скрипта звонка (BG)
> «Здравейте! Обаждам се за резервация. Имате ли свободни места за екскурзията
> „{{excursion}}" на {{date}}? Трябват ни {{seats}} места. Благодаря!»
> — выслушать, классифицировать ответ в `available`.

### Acceptance criteria
- [ ] При оформлении заказа стартует звонок по номеру из таблицы.
- [ ] Менеджеру сразу приходит «звоню…».
- [ ] По завершении звонка приходит одно из 4 уведомлений с числом мест (если назвали).
- [ ] Если номер пустой/неверный — бот честно пишет, что позвонить не вышло.
- [ ] Результат звонка дописывается в строку заказа во вкладке «Заказы» (колонка «Места: статус»).

### Заметки/риски
- Договориться с компаниями, что им может звонить автоассистент (этикет/частота).
- Для резерва: если бот не дозвонился — оставить кнопку «позвонить ещё раз».
