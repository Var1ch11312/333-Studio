# AMUR.BG — Ръководство за администратора

## Достъп до Admin панела

1. Отворете браузъра → `amur.bg/admin`
2. Въведете Admin PIN кода
3. Вие сте вътре

---

## Раздел: Поръчки

### Какво виждате

Таблица с всички поръчки в реално време. Колони:
- **ID** — уникален номер (кратка версия за справка)
- **Клиент** — телефон и адрес
- **Сума** — в EUR и BGN
- **Статус** — текущото състояние
- **Hub** — кой флорист обработва
- **Дата** — кога е поръчана

### Статуси

| Статус | Какво означава | Следващо действие |
|---|---|---|
| `created` | Поръчка създадена, чака плащане | Изчакайте Stripe |
| `paid` | Платена, изпратена към флорист | Автоматично |
| `crafting` | Флористът прие и прави букета | Следете времето |
| `delivering` | Куриерът е взел букета | Очаква снимка |
| `delivered` | Доставена с фотопотвърждение | ✅ Done |
| `cancelled` | Отменена | Проверете причината |

### Филтриране

Използвайте филтрите по статус и дата за бърза справка.

### Ескалации

Получавате WhatsApp при:
- Нов платен заказ
- Флористът не отговори в 5 мин → автоматична ескалация
- Всички флористи са офлайн или отказали
- Няма свободни куриери

При ескалация — свържете се с флорист или курьер ръчно.

## Раздел: Куриери

### Управление на куриерите

- **Списък** — всички регистрирани куриери с текущ статус
- **Добавяне** — Name + Phone + WhatsApp телефон
- **Деактивиране** — сложете `active = false`

### Когато куриер казва, че не получава поръчки

1. Проверете дали `is_available = true`
2. Проверете дали `active = true`
3. Проверете GPS — ако GPS е далеч от Hub-а, алгоритъмът го пропуска (радиус 1.5km)
4. Ако е без GPS — уверете се, че `hub_id` е правилен

## Раздел: Именини

Клиентите могат да се запишат за именинни напомняния. Системата изпраща WhatsApp всяка сутрин в 6:00 на хора, чиито близки имат именини днес.

- Виждате списъка с абонирани клиенти
- Можете да добавите/премахнете ръчно

## AI Агенти (Бухгалтер, Юрист, Маркетолог)

Агентите работят автоматично:
- **Бухгалтер** — 1-ви и 15-ти в 8:00 — анализ на приходи, разходи, данъци
- **Юрист** — 1-ви и 15-ти в 9:00 — правни препоръки за оптимизация
- **Маркетолог** — всеки понеделник в 7:00 — анализ на конверсии и реклама

**Получавате резюме в WhatsApp** след всеки агент. Пълен отчет се записва в базата данни.

### Ръчно стартиране на агент

```bash
curl -X GET https://amur.bg/api/cron/agent-accountant \
  -H "Authorization: Bearer [CRON_SECRET]"
```

Заменете `agent-accountant` с `agent-lawyer` или `agent-marketing`.

## Управление на каталога (текущо само в Supabase)

Добавяне/промяна на букет:
1. Supabase Dashboard → Table Editor → products
2. Добавете ред с: `title`, `price_eur`, `flower_count`, `hub_id`
3. Качете снимка в Storage → `product-images` bucket → копирайте URL в `image_url`

## Управление на Hub-ове

Hub-ове се управляват в Supabase:
- `status = 'online'` — активен, получава поръчки
- `status = 'offline'` — не получава поръчки
- `status = 'busy'` — временно недостъпен

Системата автоматично слага Hub на `offline` при пропуснат SLA.
За да го върнете: Supabase → hubs → update `status = 'online'`.

## При технически проблем

### Сайтът не работи
1. Проверете `vercel.com` — статус на деплоя
2. Проверете `supabase.com` — статус на базата данни
3. Проверете `status.stripe.com` — статус на плащанията

### Поръчка "заседнала" в статус `paid`
Флористът не е получил WhatsApp. Причини:
- WhatsApp токенът е изтекъл → обновете `WHATSAPP_ACCESS_TOKEN`
- Hub-ът е офлайн → проверете статуса в Supabase
- Грешен WhatsApp телефон на Hub → проверете `hubs.whatsapp_phone`

### WhatsApp не работи
- Проверете Meta Developer console → токенът изтича периодично
- Генерирайте нов System User токен → обновете `WHATSAPP_ACCESS_TOKEN` в Vercel
