# План реализации: Telegram-бот для продажи экскурсий (n8n Cloud + OpenAI)

> Внутренний бот для **менеджера** (не для клиента). Менеджер пишет боту,
> бот достаёт данные из Google Sheets, помогает подобрать остановку по отелю
> и оформляет продажу с готовым сообщением для клиента и чеком для учёта.

## Итоговая логика (как договорились)

1. Менеджер пишет название экскурсии (свободным текстом, с опечатками/в транслите) →
   бот через OpenAI находит строку в Google-таблице и присылает карточку:
   **цена (взрослый/детский), дни отправления, время, компания, краткое описание.**
2. Менеджер пишет название отеля клиента →
   бот ищет отель в таблице отелей и присылает **привязанную остановку + ссылку на Google Maps.**
3. Менеджер пишет `продай` →
   бот присылает **список наводящих вопросов** (имя, телефон, отель, кол-во взр/дет, дата, оплата).
4. Менеджер присылает заполненные данные →
   бот считает сумму, определяет остановку по отелю, записывает заказ в таблицу и выдаёт **два блока**:
   - 📩 **Сообщение клиенту** (копировать и отправить клиенту): экскурсия, дата, время сбора,
     остановка, ссылка Google Maps, что взять с собой, сумма.
   - 🧾 **Чек / учёт** (для записи и выписки своего чека): ФИО, телефон, отель, экскурсия,
     взр/дет, сумма, дата, менеджер.

## Что добавлено сверх первоначального ТЗ (необходимое для рабочего результата)

- **Контроль доступа** — бот отвечает только разрешённым Telegram ID (вы = админ, менеджеры добавляются списком).
- **Память диалога** — бот помнит контекст (выбранную экскурсию/отель), поэтому `продай` работает без повторного ввода.
- **Таблица отелей и остановок** — её ещё нет, поэтому даём шаблон (`sheets/Hotels.csv`) и
  команду пополнения «на ходу» прямо из Telegram: `добавь отель ...` (только для админа).
- **Таблица заказов** (`sheets/Orders.csv`) — каждый оформленный заказ логируется автоматически.
  Это и есть «админ-панель учёта»: вся история продаж в Google Sheets.
- **Админ-команды в чате** (для вас): добавить отель, посмотреть список экскурсий, заказы за сегодня.
- **Защита от выдумывания** — бот берёт цены/остановки только из таблиц, ничего не сочиняет.

## Архитектура (n8n Cloud)

```
Telegram Trigger (входящее сообщение)
      │
      ▼
Code «Prepare»  →  определяет chatId, текст, роль (admin/manager), доступ
      │
      ▼
IF «Authorized?»
   ├─ нет  → Telegram «Доступа нет»
   └─ да   → AI Agent (OpenAI)
                 ├─ 🧠 OpenAI Chat Model (gpt-4o-mini)
                 ├─ 💾 Window Buffer Memory (ключ = chatId)
                 ├─ 🔧 Tool: Excursions   (Google Sheets read)
                 ├─ 🔧 Tool: Hotels       (Google Sheets read)
                 ├─ 🔧 Tool: Add Hotel    (Google Sheets append, admin)
                 └─ 🔧 Tool: Log Order    (Google Sheets append)
                 │
                 ▼
           Telegram «Send Reply» (ответ менеджеру, Markdown)
```

Вся бизнес-логика живёт в **системном промпте агента** (`prompts/agent-system-prompt.md`) —
её можно править без перестройки workflow.

## Структура Google Sheets

Один документ, три вкладки:

| Вкладка | Назначение | Колонки |
|---|---|---|
| **Экскурсии** (есть) | каталог | Название, Время, Цена взрослый, Цена детский, Дни, Компания, Описание |
| **Отели** (создать) | отель → остановка | Отель, Остановка, Google Maps, Время сбора, Заметка |
| **Заказы** (создать) | лог продаж | Дата создания, Менеджер, Клиент, Телефон, Отель, Экскурсия, Взрослых, Детей, Сумма, Дата экскурсии, Остановка, Оплата, Комментарий |

> Точные названия колонок «Экскурсии» подстройте в нодах при импорте (см. README, шаг 6).

## Пошаговый план внедрения

1. **Подготовить Google Sheets**: добавить вкладки «Отели» и «Заказы» по шаблонам из `sheets/`.
2. **n8n Cloud → Credentials**: создать 3 креденшела — Telegram, OpenAI, Google Sheets (OAuth2).
3. **Импортировать** `n8n-workflow.json` в n8n Cloud.
4. **Привязать креденшелы** к нодам (Telegram Trigger, Send Reply, OpenAI Model, 4× Google Sheets).
5. **Выбрать документ и вкладки** в Google-нодах (выпадающий список).
6. **Сверить колонки** экскурсий с системным промптом (при необходимости поправить названия).
7. **Activate** workflow → бот включается на webhook.
8. **Тест**: написать боту «джип сафари» → отель → `продай` → данные → проверить два блока и запись в «Заказы».

Подробности каждого шага — в `README.md`.

## ⚠️ Безопасность (важно)

Токен Telegram-бота и ключ OpenAI вы прислали в открытом чате. **Их нужно
перевыпустить** после настройки (BotFather → /revoke и заново /token; OpenAI →
создать новый ключ, старый удалить). В этот репозиторий секреты **не** коммитятся —
они вводятся только в Credentials внутри n8n Cloud.
